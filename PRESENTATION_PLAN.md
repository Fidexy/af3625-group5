## 2. Concept map (what the audience must be able to follow)

Everything in Q5.1–5.4 hangs off these ideas; the deck should establish them
once, early, then reuse the same language and colours throughout.

- **Small country / price taker** → world price is a horizontal line; Z/A/Egypt
  cannot affect it.
- **Import rule:** domestic price **>** world price ⇒ the country imports;
  **<** world price ⇒ exports. After trade, domestic price = world price.
- **Free trade quantities:** `Q_import = Qd(world price) − Qs(world price)`.
- **Surpluses (Topic 2):**
  - Consumer surplus = area below demand, above price.
  - Producer surplus = area above supply, below price.
  - Social surplus = CS + PS (+ any government revenue / quota rent).
- **Tariff** = tax per imported unit → raises domestic price by the tariff;
  government collects **tariff revenue**; welfare falls by a **DWL** (two triangles).
- **Quota** = limit on import **quantity** → effective supply becomes
  **S + quota**; importers earn **quota rent**; welfare falls by the same two
  triangles (larger if rent goes abroad).
- **Winners/losers:** imports → consumers win, producers lose;
  protection → producers + government (or importers) win, consumers lose.
- **Net verdict:** protection *can* transfer to some groups but usually **loses
  for the country as a whole** (DWL) — the crux of Q5.2(f).

### Terminology discipline
Use the exact course phrases on slides and in speech:
"consumer surplus", "producer surplus", "social surplus", "deadweight loss
(DWL)", "tariff revenue", "quota rent", "world price", "small country /
price taker", "domestic supply plus quota". The rubric rewards correct
economic expressions.

### Format Theme and Style Guidelines (PowerPoint Design = 15%)

- **Aspect Ratio**: 16:9 (1920×1080) to match classroom projector standards; avoid 4:3 to prevent wasted flank space.
- **Background**: Solid light color (white or very light gray); avoid dark backgrounds as they reduce text legibility on standard projectors.
- **Fonts**: 
  - Body text: Sans-serif (Calibri, Segoe UI, or Arial) at **≥24pt** for body, **≥28pt** for section headers, **30-34pt** for slide titles.
  - Equations: Same font family, with variables in *italics* (e.g., *P*, *Qd*, *Qs*) and numbers in regular weight; use PowerPoint’s equation editor for proper mathematical notation.
- **Color Palette**: 
  - 1 neutral color (dark gray/black) for text and primary axes/lines.
  - 4 distinct accent colors for key elements (assign consistently):
    - Consumer surplus / loss → Color A
    - Producer surplus / gain → Color B
    - Government revenue / quota rent → Color C
    - Deadweight loss (DWL) → Color D (hatched pattern)
  - All colors must maintain sufficient contrast (≥4.5:1) against the background and remain distinguishable for color-blind viewers (always label areas with text).
- **Layout & Density**:
  - One main idea per slide; maximum 6 bullet points, ≤8 words per line.
  - Keep slide margins wide (≥1.5" from edges) for readability; use ample whitespace.
  - Avoid full-page text blocks; prioritize visual clarity over content volume.
- **Diagram Creation**:
  - Build all graphs natively in PowerPoint using shapes/curves (preferred) or export vector graphics (SVG/EMF) from tools like Python/matplotlib or Desmos; never use low-resolution screenshots of textbook figures.
  - Ensure all graphs include:
    - Labeled axes with units (e.g., "Quantity (thousands of TVs)", "Price ($ per unit)")
    - Clearly named curves (`D`, `S`, `S + quota`, `World price`)
    - Labeled key points (e.g., equilibrium, world price line)
    - Area labels (A, B, C, D) with corresponding text descriptions (e.g., "Consumer surplus", "DWL")
- **Calculations**:
  - Present calculations as **numbered steps** (Step 1, Step 2, ...), not as a single final value.
  - Show the formula first, then substitution, then result with units (e.g., "Qd = 120,000 units" or "P = $7.50").
  - Use consistent variable notation throughout (e.g., *P* for price, *Q* for quantity, *Qd* for demand, *Qs* for supply).
- **Template Setup**:
  - Define a Slide Master with:
    - Fixed title bar containing "Group 5 • Q# • slide n/N"
    - Consistent footer with slide number and group identifier
    - Predefined title slide layout (no bullet points)
    - One "full-bleed diagram" layout for graphs
    - One "text + diagram" layout for explanatory slides
  - Embed all fonts and images before distributing the file to ensure consistency across devices.
- **Export & Testing**:
  - Export final presentation as `.pptx` with fonts embedded (File → Options → Save → "Embed fonts in the file").
  - Verify all graphs display correctly on the classroom projector at full resolution; re-export if any element appears pixelated or misaligned.
- **Consistency Checklist**:
  - All slides use the same background color and font family.
  - All diagrams use the fixed color code from the palette above.
  - All text uses the specified font sizes and styles.
  - All graphs are vector-based (SVG/EMF) or high-resolution native PowerPoint shapes.
  - All calculations are shown as numbered steps with consistent variable notation.

These guidelines ensure the presentation meets the rubric's "PowerPoint design" criterion while maximizing clarity for the audience and minimizing visual distractions during delivery.
